# Figures

Each figure has a TikZ source (`.tex`), a compiled PDF, and a 2000-px PNG used by the README and `docs/concepts.md`.

| Figure | Source |
| --- | --- |
| Training-time information flows, layer-wise | `training_time_layer_wise.tex` |
| Training-time information flows, functional blocks | `training_time_functional.tex` |
| Inference-time information flows, layer-wise | `inference_time_layer_wise.tex` |
| Inference-time information flows, functional blocks | `inference_time_functional.tex` |

All four load the shared palette and TikZ styles from `figure_style.tex`; each sets only its cell size (`\figcellw`, `\figcellh`) before `\input{figure_style}`.

Rebuild every PDF and PNG from this directory with [Tectonic](https://tectonic-typesetting.github.io/) (any LaTeX with TikZ works):

```sh
./build.sh                          # all figures
./build.sh training_time_layer_wise.tex   # one figure
```

## Drafts

`drafts/` holds redrawn versions of the two layer-wise figures, generated by `drafts/make_drafts.py`:

- each position shows its pass *i−1* and pass *i* columns side by side, so depth reads are short (same position) and temporal reads go to the next position;
- the model's 8 layers are labelled L1–L8 on one vertical scale;
- temporal memory comes from L7 (the T-source) in both temporal panels;
- layers a pass doesn't run are dashed, and the prelude is one shared box because it runs once.

They are not used by the README yet.
